Dropes

Arquitectura v1 → v2

Migración del e-commerce de dropshipping — refactor de seguridad, dependencias y tipado. Comparativa capa por capa entre el repositorio original (Dropes) y la nueva versión refactorizada.

Proyecto
dropes-v2
Stack: React 19 + Vite 6
Fecha: 22-sep-2026
v1 — Dropes (original)
Frontend 9 archivos
17 componentes React + Tailwind 4. Imports framer-motion en 9 archivos pero el package.json declara motion → build roto en fresh install.
Estado in-memory
  • × Cart: solo en memoria (se pierde al recargar)
  • × Favoritos: botón Heart sin onClick
  • × Sin login / historial de pedidos
  • ! CheckoutModal: email hardcoded "cliente@tienda.com"
API client key expuesta
Llama directo a api.dropea.com/graphql desde el navegador. La API key está hardcoded en 11 archivos (frontend visible en el bundle).
Dependencias 5 inútiles
firebase · axios · better-sqlite3 · express · @google/genai
Inicializadas pero nunca importadas en el bundle frontend.
Tipado any
TypeScript en modo no-strict. Todo es any. Sin interfaces compartidas. El lint no falla ni con variables no usadas.
Build / SEO nada
  • × Sin sitemap.xml / robots.txt
  • × Sin meta tags OG ni structured data
  • × Sin validación pre-build
  • ! 14 archivos temporales sueltos en el repo
v2 — dropes-v2 (refactor)
Frontend 20 archivos
20 componentes + SearchOverlay, FavoritesDrawer, LoginModal. Imports unificados a motion/react. Diseño refrescado: Inter + Sora, glassmorphism, mesh-gradient.
Estado hooks + localStorage
  • ✓ useCart — persiste en dropes:cart
  • ✓ useFavorites — drawer lateral + badge
  • ✓ useAuth — magic email + sync cross-tab
  • ✓ useOrders — historial local (50 pedidos)
  • ✓ Email requerido y validado en checkout
API client .env
src/lib/dropea.ts lee import.meta.env.VITE_DROPEA_API_KEY. Key solo aparece en .env (no commiteado). Script de sync separado y paginado.
Dependencias −5 paquetes
Eliminadas: firebase, axios, better-sqlite3, express, @google/genai, dotenv, react-helmet-async.
95 paquetes instalados vs 200+ en v1.
Tipado strict
strict: true, noUnusedLocals, noUnusedParameters, noFallthroughCasesInSwitch. Interfaces: Product, CartItem, Customer, OrderRequest, OrderRecord.
Build / SEO completo
  • ✓ tsc --noEmit antes de vite build
  • ✓ sitemap.xml + robots.txt generados
  • ✓ OG meta + JSON-LD OnlineStore
  • ✓ Manual chunks (react-vendor, motion-vendor)
  • ✓ .gitignore cubre .env y temp_*
⚠ Seguridad: la API key de Dropea sigue siendo visible en el bundle del navegador (cualquier variable VITE_* es inlined por Vite). v2 la aísla en .env y documenta en MIGRATION.md el siguiente paso: proxy serverless o migración a Next.js 16 con API routes.
