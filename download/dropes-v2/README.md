# Dropes v2

> Refactored Dropes ecommerce storefront — React 19 + Vite 6 + Tailwind 4.
> Dropshipping via Dropea API for Spain & Portugal.

## Quick start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env and set VITE_DROPEA_API_KEY

# 3. Start dev server
npm run dev          # → http://localhost:3000

# 4. Production build
npm run build
npm run preview
```

## Scripts

| Script              | Description                                                |
| ------------------- | ---------------------------------------------------------- |
| `npm run dev`       | Start Vite dev server on port 3000                         |
| `npm run build`     | TypeScript check + production build to `dist/`             |
| `npm run preview`   | Preview the production build locally                       |
| `npm run lint`      | Run TypeScript type checking (no emit)                     |
| `npm run sync`      | Refresh `src/data/products.json` from Dropea API           |
| `npm run sitemap`   | Generate `public/sitemap.xml` from the product catalog      |
| `npm run clean`     | Remove `dist/`                                             |

## What changed from v1

See [`CHANGELOG.md`](./CHANGELOG.md) for the full diff and [`MIGRATION.md`](./MIGRATION.md) for step-by-step upgrade instructions from the original `Dropes` repo.

### Highlights

- **Security**: All API keys moved to `.env`; `.gitignore` covers all sensitive paths.
- **Dependencies**: Removed unused `firebase`, `axios`, `better-sqlite3`, `express`, `@google/genai`. Replaced `framer-motion` import (which didn't match `motion` in package.json) with the correct `motion/react` import path.
- **TypeScript strict**: All `any` types eliminated. Shared interfaces: `Product`, `CartItem`, `Customer`, `OrderRequest`, `OrderRecord`, `LocalUser`.
- **UX**: Wishlist now works (localStorage + side drawer). Search overlay added. Login modal with order history.
- **SEO**: Title/description/OG meta tags in `index.html`, structured data, `robots.txt`, and generated `sitemap.xml`.
- **Checkout**: Email is now required and validated (no more fake `cliente@tienda.com`). Phone regex for ES/PT. ZIP code validation for Spain.
- **Design**: Refreshed visual identity — Inter + Sora typography, soft mesh gradient backgrounds, glassmorphism navbar/buttons, gradient accents.

## Security considerations

The Dropea API key is exposed in the browser bundle (any VITE_* env var is). This is acceptable for a low-privilege public dropship API, but for true production-grade security you should:

1. **Proxy via serverless** — Move the `createOrder` call behind a Vercel/Cloudflare function that holds the real key and adds per-IP rate limiting.
2. **Migrate to Next.js 16** — Move the call into an API route + server-side rate limiting. See `MIGRATION.md` for the recipe.
3. **Rotate the key periodically** — Especially if you suspect leakage.
